# (Mostly) OpenAI Sora output circa 2025-2026

An important historical record of OpenAI Sora prompting and outputs prior to OpenAI shutting down Sora. Prompts are in the description of each relevant commit and as shown below in selected images. While most images have been generated by OpenAI Sora, unfortunately during archival some items eg. "Wildhaven" may have used Microsoft Copilot or other generators. Nonetheless, a majority of archive are OpenAI Sora to the best of this author's knowledge. 

All original intellectual property and brands are owned by the respective owners. Unless otherwise reasonably clear, all derivative/ remixed images are copyright CC-BY-NC (https://creativecommons.org/licenses/by-nc/4.0/).
