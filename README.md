# (Mostly) OpenAI Sora output circa 2025-2026

This is an important historical record of OpenAI Sora prompting and outputs prior to OpenAI shutting down Sora. Prompts are in the description of each relevant commit. While most images have been generated by OpenAI Sora, unfortunately during archival some items eg. "Wildhaven" may have used Microsoft Copilot or other generators. Nonetheless, a majority of archive are OpenAI Sora to the best of this author's knowledge.
