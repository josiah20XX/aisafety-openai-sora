# OpenAI Sora output circa 2025-2026

by Josiah Rhys Jacobson (concept development, prompting, curation) 

This is an important historical record of OpenAI Sora prompting and outputs prior to OpenAI shutting down Sora. Prompts are in the description of each relevant commit. Unless otherwise reasonably clear, all images are copyright CC-BY-NC (https://creativecommons.org/licenses/by-nc/4.0/). 

Part of a mission to explore and understand AI-generated, human-controlled creative work. Ultimately contributing to the promotion and advancement of AI safety.
